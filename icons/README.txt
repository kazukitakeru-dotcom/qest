■ アイコンの差し替え方法

このフォルダ内の PNG ファイルを、同じファイル名・同じサイズの
PNG 画像に差し替えてください。

必要なファイルと推奨サイズ：
  icon-72.png   ── 72×72px
  icon-96.png   ── 96×96px
  icon-128.png  ── 128×128px
  icon-144.png  ── 144×144px
  icon-152.png  ── 152×152px  ← iPhone ホーム画面用（iOS Safari）
  icon-192.png  ── 192×192px  ← Android / Chrome PWA 用
  icon-384.png  ── 384×384px
  icon-512.png  ── 512×512px  ← スプラッシュ画面・ストア等

■ iOS（iPhone）ホーム画面に追加する場合の注意
  - icon-192.png が apple-touch-icon として使用されます
  - 角丸・透過はOSが自動で適用するため、正方形のフチなし画像を推奨
  - 差し替えた後は必ずブラウザのキャッシュをクリアしてください

■ 現在のプレースホルダー
  起動確認用の仮アイコン（Q マーク）が入っています。
  アプリが正常に動作したら、お手持ちの画像に差し替えてください。
